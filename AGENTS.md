# Project Rules

Before writing code always read:

- Docs/Architecture.md
- Docs/CodingRules.md

After change code go to Docs/ChangeLog

- Write completed task in ProgressLog.md
- Write short description of your change into DecisionLog.md

Requirements:

- Always ask before change any scripts or structure of project
- Before make any feature or system, always create test case or unit test before starting code
- Always ask questions when you are unsure about a request
